# The Chrono-Toaster — The Catalogue Photo of an Impossible Gadget

A studio catalogue photograph of an impossible gadget: a brushed-chrome
toaster that toasts **time itself**. Two slices of bread printed as clock
faces pop out of its slots, one caught mid-pop, steam curling up — with a
single accessory, a small plate holding one clock-face toast slice and a
pat of butter.

The absurd job reads at a glance: this toaster doesn't brown bread, it
browns the hours.

## Run

```sh
python3 main.py
```

Writes the photograph to `/output/entry.png` (1024×1024 PNG, deterministic —
the same bytes on every run, no network).
